# Module Appointment Virtual Meeting

## Introduction

This module adds virtual meeting room management to the Lutece appointment system. It integrates with the workflow engine to automatically create and deletevideo-conferencing rooms when appointment states change.

The module is provider-agnostic: it defines the `IVirtualMeetingProvider` interface and delegates all server-specific operations (room creation, token generation, URL building) to provider libraries such as `library-livekit` or `library-meet` .

It provides the following workflow tasks:

 
*  **Add Virtual Meeting** —Creates a meeting room via the configured provider and writes the participant/agent meeting URLs into the appointment form responses.

## Configuration

Configure the module in the file `WEB-INF/conf/plugins/appointment-virtualmeeting.properties` :

| Property| Description| Default|
|-----------------|-----------------|-----------------|
|  `virtualmeeting.room.emptyTimeout` | Number of seconds to keep the room alive after the last participant leaves. Set to `0` to use the provider default.|  `0` |

The **Add Virtual Meeting** task is configured directly in the workflow back office. The configuration form allows you to:

 
* Select the video-conferencing provider (e.g. `livekit` , `meet` )
* Choose the appointment form field where the **user meeting URL** will be written
* Choose the appointment form field where the **agent meeting URL** will be written

## Usage

Add the Maven dependency to your site POM:
<dependency><groupId>fr.paris.lutece.plugins</groupId><artifactId>module-appointment-virtualmeeting</artifactId><version>1.0.0-SNAPSHOT</version><type>lutece-plugin</type></dependency>
You must also include at least one provider library:
<!-- LiveKit provider --><dependency><groupId>fr.paris.lutece.plugins</groupId><artifactId>library-livekit</artifactId><version>1.0.0-SNAPSHOT</version><type>lutece-plugin</type></dependency><!-- OR Meet provider --><dependency><groupId>fr.paris.lutece.plugins</groupId><artifactId>library-meet</artifactId><version>1.0.0-SNAPSHOT</version><type>lutece-plugin</type></dependency>
Once installed, the workflow tasks appear in the workflow configuration interface. To set up a virtual meeting workflow:

* Create two text fields in your appointment form (e.g. "User meeting link" and "Agent meeting link")
* In the workflow, add the **Add Virtual Meeting** task to the action that confirms the appointment
* Configure the task: select the provider and map the two form fields
* When the action is triggered, the room is created and the meeting URLs are written into the form fields
The agent meeting URL is also stored in the workflow task history and can be viewed in the appointment back office.

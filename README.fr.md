# Module Appointment Virtual Meeting

## Introduction

Ce module ajoute la gestion de salles de visioconférence au système de rendez-vous Lutece. Il s'intègre au moteur de workflow pour créer et supprimer automatiquement des salles de visioconférence lors des changements d'état des rendez-vous.

Le module est indépendant du fournisseur : il définit l'interface `IVirtualMeetingProvider` et délègue toutes les opérations spécifiques au serveur (création de salle, génération de jeton, construction d'URL) aux librairies fournisseur telles que `library-livekit` ou `library-meet` .

Il fournit les tâches de workflow suivantes :

 
*  **Ajouter une visioconférence** —Crée une salle de réunion via le fournisseur configuréetécrit les URL de réunion participant/agent dans les réponses du formulaire de rendez-vous.

## Configuration

Configurez le module dans le fichier `WEB-INF/conf/plugins/appointment-virtualmeeting.properties` :

| Propriété| Description| Valeur par défaut|
|-----------------|-----------------|-----------------|
|  `virtualmeeting.room.emptyTimeout` | Nombre de secondes pendant lesquelles la salle reste active après le départ du dernier participant. La valeur `0` utilise la valeur par défaut du fournisseur.|  `0` |

La tâche **Ajouter une visioconférence** se configure directement dans le back office du workflow. Le formulaire de configuration permet de :

 
* Sélectionner le fournisseur de visioconférence (ex. `livekit` , `meet` )
* Choisir le champ du formulaire de rendez-vous oùl' **URL de réunion usager** seraécrite
* Choisir le champ du formulaire de rendez-vous oùl' **URL de réunion agent** seraécrite

## Utilisation

Ajoutez la dépendance Maven dans le POM de votre site :
<dependency><groupId>fr.paris.lutece.plugins</groupId><artifactId>module-appointment-virtualmeeting</artifactId><version>1.0.0-SNAPSHOT</version><type>lutece-plugin</type></dependency>
Vous devezégalement inclure au moins une librairie fournisseur :
<!-- Fournisseur LiveKit --><dependency><groupId>fr.paris.lutece.plugins</groupId><artifactId>library-livekit</artifactId><version>1.0.0-SNAPSHOT</version><type>lutece-plugin</type></dependency><!-- OU Fournisseur Meet --><dependency><groupId>fr.paris.lutece.plugins</groupId><artifactId>library-meet</artifactId><version>1.0.0-SNAPSHOT</version><type>lutece-plugin</type></dependency>
Une fois installées, les tâches de workflow apparaissent dans l'interface de configuration du workflow. Pour mettre en place un workflowde visioconférence :

* Créez deux champs texte dans votre formulaire de rendez-vous (ex.«Lien de réunion usager»et«Lien de réunion agent»)
* Dans le workflow, ajoutez la tâche **Ajouter une visioconférence** àl'action qui confirme le rendez-vous
* Configurez la tâche : sélectionnez le fournisseur et associez les deux champs du formulaire
* Lorsque l'action est déclenchée, la salle est créée et les URL de réunion sontécrites dans les champs du formulaire
L'URL de réunion agent estégalement stockée dans l'historique de la tâche de workflow et peutêtre consultée dans le back office des rendez-vous.
